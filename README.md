# ajedrezchileno.cl

Portal del ajedrez chileno: calendario de torneos, noticias, ranking FIDE de Chile, base de datos de partidas para preparar rivales y campeones nacionales.

Sitio estático de un solo archivo (`index.html`), listo para publicar en Vercel, Netlify o GitHub Pages.

Fuentes: Federación de Ajedrez de Chile (torneos), AJEFECH (noticias y campeones), FIDE (ranking) y transmisiones de Lichess (partidas, CC0).
